# campus-opportunity-hub

校园活动与机会信息平台，面向新生筛选与发布活动信息

## 在线访问

- GitHub Pages：<https://68b8kyw4br-collab.github.io/campus-opportunity-hub/>

## 目标

- 帮助新生快速发现学校、学院和学生发布的活动与机会
- 区分“可直接参与”“信息待确认”“高风险/可疑”的内容
- 支持学生自主发布活动与招募信息，并保持到刷新后仍可查看

## 运行方式

### 在线使用

直接打开 GitHub Pages 链接即可访问：

<https://68b8kyw4br-collab.github.io/campus-opportunity-hub/>

### 本地预览

如果需要在本地开发或预览，可在项目目录执行：

```bash
python3 -m http.server 8000
```

然后访问：

<http://localhost:8000>

> `localhost` 仅用于本机开发预览，不是内网 IP，也不会作为对外分享链接。对外访问请使用上面的 GitHub Pages 地址。
